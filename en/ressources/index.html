Deep Learning with PyTorch↗

Machine Learning with Python Cookbook↗

Gavin Hackeling

Recettes pratiques : prétraitement, modèles, évaluation et mise en production.

Designing Machine Learning Systems↗

Chip Huyen

Concevoir des systèmes de ML en production : données, entraînement, déploiement et surveillance.
